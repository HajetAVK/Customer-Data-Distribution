# Customer-Data-Distribution

# Анализ распределения данных о клиентах

## 📊 Этапы анализа
1. **Загрузка и первичный осмотр:** Проверка типов данных и структуры датасета.
2. **Предобработка:** Проверка на наличие пропущенных значений (пропусков не обнаружено).
3. **Описательная статистика:** Расчет среднего, медианы, стандартного отклонения и квартилей.
4. **Визуализация:** Построение гистограммы распределения (с оценкой плотности KDE) и диаграммы «Ящик с усами» (Boxplot) для выявления выбросов.
5. **Проверка гипотез:** Использование теста Шапиро-Уилка для проверки нормальности распределения.

## 💡 Ключевые выводы (Инсайты)
* **Наличие выбросов:** В данных обнаружено аномальное значение (60), которое значительно превышает основную массу данных (диапазон 5–35).
* **Ненормальное распределение:** Тест Шапиро-Уилка показал `p-value = 0.0020` (< 0.05). Это означает, что данные **не подчиняются нормальному распределению**. Распределение имеет правостороннюю асимметрию (скошено влево).
* **Рекомендации для бизнеса:** 
  * Основная целевая аудитория сконцентрирована в диапазоне значений от 5 до 35.
  * Клиенты со значением 60 — это отдельный сегмент (возможно, VIP), для которого требуются отдельные маркетинговые подходы.
  * Использование среднего значения (21.06) для описания типичного клиента может быть некорректным из-за выброса, опираться стоит на медиану (20.0).
